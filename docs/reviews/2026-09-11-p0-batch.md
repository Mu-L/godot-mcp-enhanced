## 三、已知限制(刻意决策,留痕)

1. **用户项目多实例日志 race 不防护**:enhanced 不擅自改用户 project.godot;MULTI_INSTANCE 对同一用户项目开多实例的 rotate race 为已知边界(P0-2 契约测试注释留痕)。后续若需,可在 instance spawn 处做 CLI 分流专项。
2. **monitor 读数统一迟一帧**:帧末采样(process_priority=1000)评估后不做——bridge `_process` 承担帧定时输入注入(send_input_sequence 的 at_frame 语义),整体移帧末会使输入生效帧偏移一位;决策注释在 `mcp_bridge.gd` `_ready`,时间线形状无损。
3. **callv 返回 null 的残余歧义**:预检拦住静态可判定的不可达组合;typed array 元素级转换失败等极端场景仍可能返回 null(方法本身合法返回 null 与之不可区分,Godot 语义限制)——诚实边界,错误消息已最大化自解释。
