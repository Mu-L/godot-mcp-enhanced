## 值得进 memory 的工程教训

1. **JSONC 配置丢失 bug 根因**: 标准 JSON.parse 把含注释的合法 JSONC(Zed settings.json)当损坏文件 → adapter 走 backup + 覆盖路径 → 用户全部配置静默丢失。修复必须 parse 前 strip 注释,且必须字符级状态机(非正则)保护字符串内的 // 和 ,。

2. **字符级状态机优于正则**: 朴素正则 `s.replace(/\/\/.*$/gm, '')` 会误删字符串内 URL;字符级状态机通过 inString 状态显式区分结构位置和数据位置,是处理 JSONC 的正确范式。

3. **stripBom 先 stripJsonc 后 的顺序约束**: BOM 是首字符字节标记,必须在 stripJsonc 前删除,否则 stripJsonc 会把 BOM 当普通字符 push 进输出。
