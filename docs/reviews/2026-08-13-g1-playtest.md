## 工程教训(进 memory)

1. **MCP 新方法必须同步 tool schema 描述,不止路由代码**:CONTROL_METHODS Set 接入 ≠ AI 可发现;description 是 AI 唯一发现机制,漏更新等于功能隐性残疾(I-1)。同类于 `independent-copy-sync-ci-blindspot`:代码与对外契约两份副本,CI 不校验内容一致。
2. **结构化条件 vs Expression 的安全权衡**:satellite 用 Expression(灵活但绕白名单开 RCE 洞);enhanced 用结构化 `{path,property,op,value}[]`(安全,不绕白名单)。能力限制(只能 property 比较)是安全取舍,文档化即可。可复现:step_until 条件求值。
3. **延迟通道临时变量串行安全的充要条件**:set 后同调用栈/同循环迭代立即 consume,且仅该路径写。_pending_control_step_until_result 满足故安全;跨帧持有需重新评估。
