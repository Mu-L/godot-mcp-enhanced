## 四、memory 教训(审查者 + 实现者合并)

1. **校验先于副作用,无一例外**(B-1):参数校验全部通过才允许触碰状态;"沿用既有模式"要沿用到校验顺序这一层。
2. **移植键名/常量必须 grep 写入方核对,不能信注释**(I-2 + 大小写连环)。
3. **死代码钳位是意图漂移的化石**(I-1):`if x<0: x=0` 紧跟 `x=0` 永不可达——应怀疑"想做条件重置写成了无条件"。
4. **加严路径校验先 grep 既有合法调用形态**(drive-relative 误伤):拒绝式防御的红线测试必须含"合法用法放行"锚。
5. **诊断"环境怪象"前穷尽输入差异**(大小写误诊):同函数不同环境不同结果时,先用 JSON.stringify 逐字节比对输入,再怀疑环境。
