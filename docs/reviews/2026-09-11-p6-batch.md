## 值得进 memory 的教训(审查者提炼)

1. **模板 header 传染**:共享 GD 模板常量(SCENE_TREE_HEADER)内联 nonliteral load 后,所有消费方被通道二分——审查此类安全批必须 grep 模板常量的**全部间接消费方**(含 wrapAssertionCode/wrapSnippet 这类包装函数的调用点),不能只看直接 import 清单。
2. **修复面 = 测试红灯面的陷阱**:误拦的暴露面由 e2e 覆盖决定(15 工具 16 红),修复只修暴露面;未覆盖的同等暴露面(workflow acceptance)静默回归。修"误拦类"问题按威胁模型全量枚举消费方,而非按红灯清单打勾。
3. **mock executor 对沙箱行为结构性假绿**:凡涉及 scanGdscriptSandbox 行为变更的回归,必须至少一条不 mock executor 的真链路用例(p6-batch 直测 scanGdscriptSandbox 本身是对的,但缺"工具→executor 接线"层真链路锚,导致 B-1 漏网——已补)。
