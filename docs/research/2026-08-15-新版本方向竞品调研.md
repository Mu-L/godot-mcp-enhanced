# v0.30+ 新版本方向竞品调研

> **调研日期**：2026-08-15（基线 v0.29.0，已发版）
> **调研方法**：GitHub search API + 官网/官方博客抓取（web-reader）+ zread 仓库阅读 + 论坛/生态文章。所有数字来自当日实测抓取，非转述。
> **与上轮调研关系**：上轮覆盖 7 个源码级竞品（2026-05-07 `Godot_MCP_市场对比分析.md`）+ breakpoint/better-godot-mcp/heren/MCP 规范（2026-08-05 plan）。本轮聚焦**之后出现的新玩家、头部项目成功要素、生态级趋势**，不重复源码级工具清单对比。

## 一、竞品格局三大变化

### 1.1 星数霸主易主：hi-godot/godot-ai（1680★，5 月调研漏掉）

GitHub search API 实测（2026-08-15）：`hi-godot/godot-ai` 1680★/100 fork，2026-04-12 创建，MIT，GDScript+Python。**星数是 enhanced（83★）的 20 倍**，且不在 5 月源码对比的 7 项目清单里。

| 维度 | godot-ai 实测（README+repo structure） | enhanced 现状 |
|------|---------------------------------------|--------------|
| 架构 | EditorPlugin 自启 Python FastMCP，**HTTP :8000/mcp** + WS :9500 回连 | 三层（headless+editor+bridge），**纯 stdio** |
| 工具 | ~41 tools / 120+ ops | 33 tools / 199 actions |
| 分发 | **Asset Library + 新 Asset Store 双上架**，编辑器 AssetLib 一键装 | 仅 Asset Library（v0.29.0 材料已备） |
| 客户端配置 | **编辑器 dock 内 20+ 客户端自动配置**，每行 Configure 按钮，配置漂移检测（amber banner） | CLI `setup` 14 客户端（无 dock UI） |
| 社区 | Discord + 演示 GIF（cyberpunk HUD 2 小时零代码） | 无 Discord |
| 工程 | 90+ GDScript 测试 + Python 单测/集成，circuit breaker、orphan reaper、self-update 安全、telemetry | 306 测试文件，审计/门控/确定性 playtest/录制（能力更深） |

**关键判断**：godot-ai 赢在**分发与上手体验**（一键安装、dock 自动配置、演示营销、Discord），不在能力深度。它的 README 通篇不提 headless、确定性 playtest、审计、安全门控——这些 enhanced 的护城河原封未动。但 Python+uv 依赖链是它的真实弱点（README 里 pywin32 硬链接锁死坑写了整段 workaround，Windows 体验有债）。

### 1.2 付费玩家换赛道：GodotIQ —— "理解层"（intelligence layer）

官网实测抓取（godotiq.com，2026-08-15）：38 tools = 24 免费 + 14 Pro，**$19 一次性买断**。口号："Other MCPs give AI hands. GodotIQ gives it a brain."

Pro 层 14 个"智能工具"分五类，每类对应一个真实痛点：

| 类别 | 工具 | 解决的痛点（官网原案例） |
|------|------|------------------------|
| 空间智能 | `godotiq_scene_map` / `godotiq_placement` / `godotiq_spatial_audit` | agent 放物体 (2,0,0) 撞进墙里，10 轮迭代才修好 → 放置前校验，一次到位 |
| 代码理解 | `godotiq_dependency_graph` / `godotiq_signal_map` / `godotiq_impact_check` | 改一个信号 5 个系统静默坏 → 改前看到 18 个依赖方 |
| 流追踪 | `godotiq_trace_flow` | UI 显示 "Unknown"，agent grep 30 分钟 → 沿 DB→manager→UI 数据链直达 |
| 项目记忆 | `godotiq_project_summary` / `godotiq_file_context` | **"Survives context compaction"**（抗上下文压缩的项目摘要） |
| Token 优化 | `detail: brief/normal/full` 全工具分级 | 宣称常规操作省 80% token |

其他事实：18 个工具免 addon 纯文件系统可跑；1,446 自动化测试；**仅支持 Godot 4.0–4.4**（enhanced 已到 4.5–4.7，有代差窗口）。

**关键判断**：这验证了 enhanced 之前 G4/G5 评估时存疑的"理解层"市场需求是真实的、有人付费。G4/G5 当时结论是"不照搬竞品重路线、先补零依赖只读 grep"——现在市场证据变了，值得重估（enhanced 有 tscn parser 这张 GodotIQ 没明说的牌）。

### 1.3 AI 游戏 QA 成为付费意愿最强的用例（Unreal 侧已验证）

StraySpark（商业 Unreal MCP $89.99，305 工具）2026-03-24 教程《AI-Powered Game QA and Playtesting》给出了完整模式：

- **agent 当测试执行器+评估器**：自然语言测试规范（前置条件/步骤/Verify 断言）→ MCP 工具调用序列（spawn/读属性/存读档/比对）→ PASSED/FAILED 报告（含复现步骤）
- 高价值场景排序：**存读档完整性 > 库存边界 > 任务状态机乱序完成 > 战斗数值 > 碰撞**（他们实测抓到"存档不保留堆叠数"这类人测不出的 bug）
- **夜间定时跑 + 回归 diff + 回归二分**（binary search 定位引入 commit）
- 混沌测试（断网存档/强 GC/低内存）、生成式测试规范（读代码自动生成边界用例）、重构对比测试
- 结论原话："AI testing catches 60-70% of bugs that would otherwise reach players"

同周期信号：Square Enix 公开宣布用 AI 做 QA 测试；Razer QA Companion-AI（视觉回归）、TITAN（RL 导航找卡点）、ManaMind（商业 AI 平测平台）形成品类。

**关键判断**：enhanced 已有该品类的**全部原语**——`freeze`/`step_until`（确定性推进）、`snapshot`/`restore`（状态回滚）、`runtime_assert`（断言）、`monitor`/`watch`（采样/信号）、`recording`（录制回放）、`screenshot`+`screenshot_diff`（视觉验证）——但**缺一层"测试套件编排"**（规范解析→编排执行→报告聚合→回归 diff）。StraySpark 在 Unreal 侧收 $89.99，Godot 侧**无人占位**。

## 二、生态动向

### 2.1 MCP 2026-07-28 spec（8 月调研已知 SDK v2，本轮补齐两点）

- **Tasks 扩展转正**：`io.modelcontextprotocol/tasks`，poll 型 `tasks/get` + 新 `tasks/update` + `subscriptions/listen` 统一流。契合 enhanced 的长跑操作（export 可达分钟级、playtest 会话、e2e 套件）。
- **MCP Apps 扩展**：`ui://` 资源 + 客户端沙箱 iframe 渲染交互 HTML（SEP-1865，2026-01-26 博客，FastMCP 4 已支持低层 API）。**enhanced 的只读 dashboard（`src/dashboard/`）是现成的 MCP App 候选**——升级后在 Claude/VS Code 会话内直接看渲染面板，属差异化。
- ⚠️ **债务倒计时**：Roots / Sampling / Logging **正式废弃，12 个月窗口**（SEP-2577）。enhanced 用了"MCP Roots 动势注入"（2026-08-05 plan 1.1 节自述）→ 需排替代方案。HTTP+SSE 同步废弃。

### 2.2 Godot 4.7 stable（2026-06 底）+ 新官方 Asset Store

- 4.7 亮点：HDR 输出、AreaLight3D、**新 Godot Asset Store**（store.godotengine.org，带权限控制/受限用户列表）、drawable textures、Android XR/Steam Frame 生产就绪。4.7.1 已出。
- enhanced 已支持 4.5–4.7 ✓，但**只上了 Asset Library，未上 Asset Store**；godot-ai 双上架且把"AssetLib 一键安装"写进 README 第一屏。官方提交指南：docs.godotengine.org/en/stable/community/asset_store/submitting_to_asset_store.html。

### 2.3 长尾新信号（GitHub search 实测 2026-08-15）

| 信号 | 项目 | 含义 |
|------|------|------|
| Agent harness 原生化 | `Smalldy/godot-bridge`（8/14 新建）：DSH（DeepSeek Harness）插件直接以原生 agent 工具驱动运行中游戏，"replaces the godot-mcp MCP server" | MCP 之外出现第二接入形态；enhanced 的 bridge 协议若被 harness 直接复用反而是机会 |
| CLI+Skill+MCP 三位一体 | `aigengame/godot-agent`（29★）：结构化 JSON/schema 输出 + agent skill | skills 分发成为标配预期 |
| 多 agent 分工编排 | `Thepizzapie/BuildersGate`（21★）：art/gameplay/narrative/QA/audio 各一个 session | "QA session"再次印证方向 2 |
| Skills 生成系统 | Unity-MCP（IvanMurzak）`setup-skills` CLI + 编辑器"Auto-generate skills"：**按项目引擎版本/已装包/OS 自动生成 markdown skill** | enhanced 的 `setup_project_rules` 演进方向：不只发规则模板，还按项目实况生成 |
| 为 agent 设计游戏 | `blisspixel/VibeSnake`：确定性规则 + verified replays + "Agent Arena" | 小众但与 enhanced 确定性 playtest 能力同频 |
| Summer Engine 营销话术 | 其对比表宣称 MCP server "cannot interact with the running engine / self-correct from a running game" | **对 enhanced 是免费的反向广告素材**——bridge 层就是干这个的，且免费开源 |

## 三、enhanced 现状定位（诚实对比）

**护城河（无人复制，0.26–0.29 刚巩固）**：三层架构、确定性 playtest（freeze/step_until/snapshot/restore）、审计+确认门控+输出防伪造、录制回放、路径白名单、capability profile、trace_id、306 测试文件、14 客户端 CLI setup。

**相对劣势（按影响排序）**：
1. **分发差距**：83★ vs 1680★，核心差在 Asset Store 缺席、无 dock UI、无 Discord、无演示物料 —— 不是能力问题
2. **纯 stdio**：无 HTTP transport（godot-ai 的 `claude mcp add --transport http` 体验更顺，多客户端共享一个 server 实例）
3. **无"理解层"**：改信号前看不到影响面、放置不校验空间、无项目记忆 —— GodotIQ 已收费验证该需求
4. **协议债**：Roots/Sampling/Logging 12 个月废弃倒计时（enhanced 用了 Roots 注入）

## 四、v0.30+ 方向建议（按"抢分发 → 立品类 → 清债务"排序）

### 方向 A（速赢·分发）：Asset Store 上架 + HTTP transport + dock 自动配置

- **A1** 提交新 Godot Asset Store（v0.29.0 提交材料已有基础，改造成本 XS–S）。
- **A2** HTTP transport（`--http` 模式，P3-3 立项即做）：SDK v2 已支持，`ws` 依赖已在；多客户端共享实例 + `claude mcp add --transport http` 体验对齐 godot-ai。
- **A3** 编辑器 dock 内客户端一键配置（把 `src/cli/clients/` 13 适配器搬进 addon dock UI，含 godot-ai 式配置漂移提示）。工作量 M。
- 理由：1680 vs 83 的差距主要就是分发；这是投入产出比最高的一批。

### 方向 B（立品类·最强推荐）：AI QA / Playtest Suite —— 免费开源闭环游戏 QA

- 把既有原语编排成测试套件层：
  - `qa_suite` 工具（或 `qa_run` action）：markdown/结构化测试规范（preconditions/steps/verify）→ 自动 game_bridge_install → run_project → 逐步执行（input/step_until/property 断言/存读档比对）→ 聚合报告（每用例 PASSED/FAILED + 截图 + trace_id + 复现步骤）
  - CLI `npm run qa -- --nightly`：cron 触发 headless 全量跑 + 与上次结果 diff + 回归清单（对齐 StraySpark 夜间管线模式）
  - 复用 `recording`（失败用例自动留录制）、`screenshot_diff`（视觉回归）、`audit`（操作留痕）
- 理由：全部原语已就位只缺编排层；Unreal 侧 $89.99 验证付费意愿、Godot 侧无人占位；与安全护城河同向（QA 报告天然要求可信执行）；直接反驳 Summer Engine 对 MCP 的"不能闭环"话术。
- 契合 MCP Tasks 扩展：长跑套件用 task handle + poll。

### 方向 C（差异化能力）：免费开源版"理解层"

- 基于已有 tscn parser + headless 执行器：
  - `impact_check` / `signal_map`：改信号/脚本/节点前列出依赖面（防"改一处坏五处"）
  - `scene_map` 空间校验：.tscn + CollisionShape 推导可放置区域，放置/生成内容前验证
  - `project_summary` / `compact_context`：抗上下文压缩的项目摘要（autoload/场景/信号拓扑一页图）
  - `detail: brief/normal/full` token 分级推广到高频读类工具（screenshot 已有 full/thumbnail/ascii 先例）
- 理由：GodotIQ $19 验证需求且只支持到 4.4（enhanced 到 4.7 有代差）；G4/G5 旧结论可依新市场证据重估；tscn parser（5 文件 72KB）是 GodotIQ 未明说的差异化底座。
- 注意：与"简约至上"平衡——先做 impact_check/signal_map（tscn 解析已能支撑）两个最能止血的，scene_map 空间推导复杂可后置。

### 方向 D（债务清理）：MCP 2026-07-28 对齐

- Roots 替代方案（12 个月倒计时，影响"路径白名单动态注入"）；Logging/Sampling 使用面排查。
- MCP Apps：dashboard 以 `ui://` 资源成为 MCP App（FastMCP 4 模式可参照），dashboard 现有"独立只读 CLI 进程"约束不变，只是多一个宿主形态。
- Tasks 扩展接 export/playtest/qa_suite 长任务。

### 建议取舍

| 版本 | 内容 |
|------|------|
| v0.30 | A1 + A2（分发速赢）+ B 的 `qa_run` 最小闭环（单场景/属性断言/报告） |
| v0.31 | B 收尾（nightly diff + 录制集成）+ C 的 impact_check/signal_map |
| v0.32+ | A3 dock + C 剩余 + D 按倒计时排期 |

**明确不建议**：照抄 godot-ai 的 Python/uv 架构或 41→120 工具的数量竞赛；付费墙（enhanced 定位免费开源差异化）。
